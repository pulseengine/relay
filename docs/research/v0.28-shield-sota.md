# v0.28 — Runtime-Assured / Shielded Agile Control SOTA (research note)

Scope: the capstone "moat". A learned/NMPC agile policy flies for
performance; a runtime SHIELD falls back to the v0.23 Lyapunov-certified
geometric SE(3) controller whenever the policy would leave the proven safe
set. The shield + certified fallback carry the guarantee; the policy is
unverified.

**Bottom line:** the 2024–2026 literature supports the design — carry safety
in a *shield* (verified monitor + certified fallback), treat the policy as a
black box, and switch on the **recoverable set**, not the safety boundary.
For a no_std target with a Lyapunov certificate already in hand, **discrete
Simplex switching on the Lee-2010 region is the right primitive; CBF
filtering is the fallback only for minimally-invasive blending.**

## 1. Simplex + modern Run-Time Assurance

Sha's Simplex ("Using Simplicity to Control Complexity", 2001): unverified
high-performance controller + verified baseline + a decision module that
reverts near the safety boundary. **Black-Box Simplex** (Mehmood/Sha/Stoller,
[arXiv:2102.12981](https://arxiv.org/pdf/2102.12981)) makes the key point
explicit: switch to baseline **before** the state leaves the **recoverable
set** — the states from which the baseline can keep the system safe
indefinitely. Invariance: if R is forward-invariant under the baseline and
you hand control to the advanced controller only from interior states with
one-step lookahead, control reverts whenever the *next* state would exit R,
so the realized trajectory never leaves R. Safety is by construction,
independent of the advanced controller.
[Springer](https://link.springer.com/chapter/10.1007/978-3-031-06773-0_12).

## 2. Control Barrier Functions + the closed-form filter

Ames et al. ([arXiv:1609.06408](https://arxiv.org/abs/1609.06408)): a CBF
safety filter solves a QP `min ‖u−u_policy‖² s.t. ḣ ≥ −α(h)` keeping `h≥0`
forward-invariant (aerospace RTA: ASIF). Discrete Simplex = all-or-nothing
swap; continuous CBF = minimally-invasive per-step modification. Decisive
for embedded: the **single-constraint CBF-QP has a CLOSED FORM** (one active
barrier ⇒ `u* = k(x) − R⁻¹b₁λ₁`, no solver, no alloc) — so a 1-constraint
filter *is* no_std-feasible, but needs a control-affine model of `h`'s
relative degree. ([ASIF/RTA arXiv:2209.01120](https://arxiv.org/pdf/2209.01120)).

## 3. Tying the shield to the Lee-2010 region (soundness)

Lee/Leok/McClamroch (CDC 2010): the geometric controller's region of
attraction is exactly `Ψ(R(0),R_d(0)) < 2` AND
`‖e_Ω(0)‖² < 2k_R(2−Ψ(0))/λ_M(J)` — positively invariant, with `V̇ ≤ 0` on
it. **The switching predicate is sound iff the switch set ⊆ this region.**
So define `R = {Ψ < 2 ∧ ‖e_Ω‖² < 2k_R(2−Ψ)/λ_M(J)}` and let the policy fly
only while the (predicted) state stays strictly inside R (with a delay
margin). Reverting to relay-geo from anywhere in R guarantees recovery.
[arXiv:1003.2005](https://arxiv.org/abs/1003.2005).

## 4. What is formally verifiable (the high-value deliverable)

Do NOT verify the policy. Verify the **monitor** (small, total):
- **Totality:** `margin(Ψ, ‖e_Ω‖², k_R, λ_M)` is a total function over
  floats — no panic/NaN-trap (Kani).
- **Output well-formedness:** the shield always emits exactly one of
  {policy_cmd, fallback_cmd} (Kani exhaustive on the branch).
- **Soundness:** `switch_set ⊆ region_of_attraction ⇒ forward invariance` —
  the Lean obligation, reusing the v0.23 kernel certificate (`V̇≤0` on
  `Ψ<2`); bridge lemma "predicate true ⇒ state ∈ R", then invariance is
  inherited.
Mirrors how aerospace RTA is certified (the *filter/monitor* is the
certified object, not the primary controller).

## 5. The agile policy as an unverified black box + a stand-in

Kaufmann et al., "Champion-level drone racing using deep RL" (Nature 620,
2023, [link](https://www.nature.com/articles/s41586-023-06419-4)) — the
canonical superhuman-but-unverified policy; NMPC via **acados** (RTI-SQP,
HPIPM) the optimization alternative. Both too large/non-total to verify —
exactly why they sit outside the shield. **Build the shield first against a
stand-in**: an aggressive (even deliberately destabilizing) controller that
drives toward the boundary, exercising the switch logic + the full
Kani/Lean oracle with zero learned components.

## 6. Recommendation — ranked v0.28 plan

1. **(Preferred) Discrete Simplex switch on the Lyapunov recoverable set,
   no QP.** Predicate `in_region(Ψ, ‖e_Ω‖²)` over the existing certificate;
   switch at a positive margin (delay buffer); revert to relay-geo. Embedded-
   clean, reuses the Lean certificate verbatim.
2. **Kani/Lean oracle as the gate** — the monitor's obligations (totality,
   well-formed output, switch_set ⊆ ROA ⇒ invariance). This is the
   deliverable, not the policy.
3. **Aggressive-tracking stand-in** to build/test the shield end-to-end
   before any learned/NMPC policy exists.
4. **(Defer) 1-constraint closed-form CBF filter** for minimally-invasive
   blending — no_std-feasible but more surface area (control-affine model +
   a separately-verified barrier).

**Honest scope caveat:** the v0.23 certificate is ATTITUDE/rotational —
scope v0.28's guarantee to the rotational recoverable set, or extend to the
combined position+attitude proposition before claiming full-state safety.
