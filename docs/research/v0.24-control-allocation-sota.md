# Background research — v0.24 control allocation SOTA (May 2026)

Scouted while building v0.23. Now *empirically motivated*: the v0.23
finding is a maneuver-induced yaw spin from rotor-drag coupling the
static mixer doesn't model — exactly what proper allocation fixes.

## Recommendation

**Pseudo-inverse allocation + PX4-style sequential desaturation** with
explicit **thrust ≻ roll/pitch ≻ yaw** priority and a final clamp to
[u_min, u_max], with the effectiveness matrix `B`/`B⁺` as a **swappable
per-configuration constant**, and a **monotone clamped thrust→PWM curve**
downstream.

Why: it is the minimal flight-proven upgrade from the static mixer with
real saturation handling, and every safety property maps onto our
existing Kani proof style:
- `∀i u_i ∈ [0,1]` after the final clamp — a one-line Kani postcondition,
  even simpler than the thrust-floor bound.
- Division-safety in the desaturation gain: PX4's `|d_i| ≥ 0.2` guard
  keeps the denominator SMT-safe — replicate it verbatim.
- Priority preservation: an algebraic invariant of the fixed `B`
  (sliding along the thrust column has zero torque components) → a
  Verus/SMT linear-algebra lemma, not runtime Kani.

**Crucially for v0.23's yaw bug**: model the rotor **drag torque** in `B`
(thrust ≈ kω², yaw drag ≈ bω²), so roll/pitch motor differentials no
longer leak into uncommanded yaw — the static mixer's missing physics.

## Forward-compatibility (why this `B`-swappable design)

- **hex/octo** = a different constant `B` (null space available for
  secondary objectives). Bound proofs unchanged.
- **rotor-loss (v0.26)** = swap to `B_k` (zero the failed column),
  recompute `B_k⁺`; the `u∈[0,1]` + priority proofs **port per `B_k`**.
  For a quad single-failure the established move is yaw-relinquish +
  reduced-attitude spin (Mueller & D'Andrea, ICRA 2014, DOI
  10.1109/ICRA.2014.6906588).
- **INDI (v0.25)** = feed increments `Δν` + local effectiveness `B(ω)`
  into the *same* allocator; the clamp/bound proofs compose.

## Deferred

**Active-set / WLS QP** (Härkegård, CDC 2002, DOI 10.1109/CDC.2002.1184694;
QCAT) — optimal for over-actuated frames but needs a *certified
fixed-iteration solver* proof (unbounded loop + in-loop float LA), a
research-grade effort. The v0.27+ "optimal allocation" milestone, after
fault tolerance flies on the simpler verified allocator.

**Fully nonlinear / learned allocation** (arXiv:2604.06337) —
essentially unverifiable by Kani/SMT. Skip; the monotone thrust→PWM curve
captures the worthwhile, provable half.
