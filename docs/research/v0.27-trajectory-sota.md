# v0.27 — Quadrotor Trajectory Generation SOTA (research note)

Scope: trajectory generation for the falcon, on the existing stack
(IEKF, geometric SE(3) `relay-geo` + verified Lyapunov certificate, ADRC,
Kani-verified allocation, P-D outer loop on step setpoints). Mandate:
formally-verifiable, no_std/no_alloc flight code.

## 1. Differential flatness — the enabler

Mellinger & Kumar (ICRA 2011): a quadrotor is **differentially flat** in
`σ = (x,y,z,ψ)`. Every state + input is an algebraic function of these
outputs and their derivatives up to **snap** (4th pos derivative) + yaw
rate — no dynamics integration. So a planner works in flat space and hands
the controller exact feedforward. The map (Mellinger-Kumar; Faessler 2018
[arXiv:1712.02402](https://arxiv.org/pdf/1712.02402)):

- **Thrust axis:** `t = a + g·e₃` (specific force); `b₃,des = t/‖t‖`.
  Yaw → `b₁,c=(cosψ,sinψ,0)`, `b₂=b₃×b₁,c` (norm), `b₁=b₂×b₃` ⇒ `R_des`.
- **Collective thrust:** `c = b₃ᵀ t`.
- **Body-rate ff (from jerk j):** `ċ=b₃ᵀj`; `ω_x=−b₂ᵀj/c`, `ω_y=b₁ᵀj/c`,
  `ω_z` from `ψ̇` projected on `b₃`.
- **Ang-accel ff (from snap s):** a 2nd differentiation gives `ω̇`
  algebraically in `s,j,c,ċ,ψ̈`.

For Relay: the planner emits `(p,v,a,j,s,ψ,ψ̇,ψ̈)` → exactly the
`(R_des, ω_des, ω̇_des, c)` feedforward `relay-geo` consumes. **The current
step-setpoint P-D loop is the degenerate case (higher derivatives = 0), so
trajectory feedforward is a strict drop-in superset — no `relay-geo`
change.**

## 2. Minimum-snap / -jerk polynomials

Mellinger-Kumar minimize `∫‖σ⁽⁴⁾‖²` over piecewise polynomials (deg 7–9),
C⁴ at joints; quadratic cost → QP `min cᵀQc s.t. Ac=b`. Snap is the right
objective (couples to angular accel → torques → feasibility).
**Richter-Bry-Roy (ISRR 2013)** fixed the conditioning: use endpoint
DERIVATIVES as variables, partition fixed/free, solve UNCONSTRAINED in
closed form `d_P*=−R_PP⁻¹R_FP d_F` — stable for high order. Time allocation
(segment durations) is the remaining nonconvex knob.
**no_std:** fix degree (7) + max segment count ⇒ compile-time `[[f32;N];N]`,
the Richter closed form is fixed small matrix ops, no alloc.

## 3. Motion primitives (Mueller, Hehn & D'Andrea, T-RO 2015)

The embedded/replanning sweet spot. Per axis (decoupled x,y,z), given
initial `(p,v,a)` + any subset of final `(p,v,a)` + duration T, the
**jerk-minimizing** trajectory is a **quintic** whose coeffs `(α,β,γ)` come
from a closed-form small inverse — **no optimizer**. Crucially it gives
**closed-form input-feasibility tests**: thrust/rotor ∈ `[f_min,f_max]` and
body-rate ≤ `ω_max` over `[0,T]` via **recursive interval subdivision**
(sufficient, cheap, no sampling miss). The real-time choice over a global
QP: constant-time, deterministic feasibility verdict, per-axis, fixed-size.
Composes with `relay-geo` exactly as §1. [ETH PDF](https://www.flyingmachinearena.ethz.ch/wp-content/publications/2015/mueTRO15.pdf),
[code](https://github.com/markwmuller/RapidQuadrocopterTrajectories).

## 4. What is formally verifiable (the edge), ranked

1. **Polynomial evaluator bounds (Kani):** fixed-degree coeffs in a box ⇒
   output `p,v,a,j` in declared ranges over `t∈[0,T]`. Kani's domain.
2. **Input-feasibility soundness (Kani):** prove the Mueller thrust/rate
   test is SOUND — "feasible" ⇒ the bound truly holds. **Highest-value
   oracle**: makes "trajectory is dynamically feasible" a *checked*
   property.
3. **Cᵏ continuity as algebraic identity (Lean/Verus):** `p_i⁽ᵏ⁾(T_i) =
   p_{i+1}⁽ᵏ⁾(0)`, k=0..4 — a polynomial identity, clean Lean lemma
   (mirrors the v0.23 certificate style).
4. **Flatness-map totality/boundedness (Lean/Verus):** `‖t‖>0` ⇒ the
   `…/c` divisions are total; bound `ω` given bounded jerk + `c≥c_min`.

## 5. Newer (2024–2026)

- **MINCO/GCOPTER (Wang T-RO 2022)** — SOTA representation: deg-5 polys
  parametrized by waypoints+durations, analytic gradients through a banded
  system, joint space-time optimization at linear cost. Cleaner to
  *optimize* but heavier (sparse solve + L-BFGS) — NOT a natural
  no_std/no_alloc proof target.
- **Learning/MPC** (transformer time-alloc, GP/Deep-Koopman MPC) — accuracy
  wins, not provable.
- **Verdict:** for a provable no_alloc baseline, **min-snap (Richter closed
  form) + the Mueller primitive remain the right baseline**, not MINCO.

## 6. Recommendation for v0.27 (ranked)

1. **Representation:** Mueller per-axis quintic primitive (fixed-size,
   closed-form, alloc-free) as the core; add a fixed-degree/segment
   min-snap path later for multi-waypoint.
2. **Feedforward:** the §1 flatness map as a pure function
   `(p,v,a,j,s,ψ,ψ̇,ψ̈) → (R_des, ω_des, ω̇_des, c)`, routed through the
   existing position loop (step setpoints = the derivatives-zero case). No
   controller change.
3. **The gate:** **Kani-verify the Mueller input-feasibility predicate is
   sound** + evaluator output bounds; **Lean C⁴-continuity lemma** at
   joints. Extends the runnable+kernel-verified-certificate pattern.

MINCO and learned/MPC generators are explicitly out of scope (un-provable /
alloc-heavy), noted as future work.

**Caveat:** the §1 flatness equations are the canonical Mellinger-Kumar/
Faessler form; check signs/normalization against `relay-geo`'s conventions
before encoding (the structure — thrust=projection, ω from jerk/thrust, ω̇
from snap — is standard).
